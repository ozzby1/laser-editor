Compare dithering methods on your photo

All four previews use the same crop, tonal adjustments and Photo Type. Use the button below a preview to apply that method to the main laser-ready output.

Floyd-Steinberg

Balanced contrast and detail. A reliable first choice for most photographs and materials.

Atkinson

A lighter, softer pattern that can keep skin tones and heat-sensitive materials cleaner.

Jarvis

Smooth tonal transitions with a denser pattern. Useful when the material can hold fine dots.

Ordered / Bayer

A regular, visible dot pattern. Best for graphic looks, raster logos and predictable repetition.

Recommended starting points

Portrait

Start with Floyd-Steinberg. Try Atkinson when skin or highlights look too dark. Use Normal Photo on light materials and Negative on dark surfaces.

Logo

Start with Ordered / Bayer for a regular raster pattern. For clean outlines and solid shapes, a vector logo in your laser software is usually better than dithering.

Wood

Start with 254 DPI and Floyd-Steinberg. Try Atkinson if dots spread or shadows burn together. Keep dark areas open and test on the same wood.

Slate

Start with Negative, 254–300 DPI and Floyd-Steinberg. Try Jarvis for smoother tones if the slate keeps fine light marks.

Metal

For dark anodized or coated metal, start with Negative and Floyd-Steinberg or Jarvis. Use 300–508 DPI only when the laser spot and coating can reproduce it. Bare stainless steel, marking spray and fiber marking require separate tests.

How to choose the correct output size?

The output size in mm should exactly match the real physical size of the engraving area on your material.

Example: If you want to engrave a portrait on a wooden plate with a width of 80 mm, set the width to 80 mm and choose 254 DPI. The tool will create an image about 800 px wide. Changing DPI keeps the same physical size but recalculates the pixel count, and the advanced pixel-width control can fine-tune the final raster when your laser software needs an exact pixel size.

ℹ️ Formula: width in px = (width in mm ÷ 25.4) × DPI

Tips for better results

Input photo quality

Use sharp, evenly lit photos with visible detail in the face, object or texture. Crop away empty background before dithering so the laser-ready pixels focus on the important area.

Preview before engraving

Switch between Original + Output, Output and Material Preview. The simulation is only a guide, but the power slider can warn you when stronger settings may darken, spread or flatten the real mark.

Test engraving

Always test on an offcut of the same material. Real results still depend on laser type, focus, lens, speed, power, coating and the exact surface.

Laser software settings

Import the PNG or BMP as Passthrough or Threshold. The dithering is already included in the file, so additional image processing may make it worse. Use the embedded DPI metadata or manually set the same physical width if your software ignores metadata.
